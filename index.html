Up and running in three steps

  1. Install the package with your favorite package manager.
  2. Import the stylesheet once at the root of your app.
  3. Use the classes or components anywhere you like.
See it in action 
// 1. Install
npm install navi-ui

// 2. Import once
import 'navi-ui/styles.css';

// 3. Use anywhere
<button class="btn btn-primary">
  Hello, Navi
</button>

Frequently asked questions

Is Navi UI free to use?

Yes. Navi UI is open source and free for personal and commercial projects.

Do I need a specific framework?

No. The core is plain CSS and a few lines of vanilla JavaScript, so it works with any stack.

How do I customize the theme?

Override the CSS custom properties (like --primary or --radius) on :root or any container.

Does it support dark mode?

Yes — it follows the system preference automatically, and you can force a theme with data-theme="dark" or "light".
